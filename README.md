# TimeIsMoney

자바 수업 기말 프로젝트용 로컬 달력 가계부입니다. Java Swing 화면에서 주간 근무 일정을 설정하고, 예정 급여와 지출을 달력에서 확인합니다. 기록은 이 PC의 CSV 파일에 저장됩니다.

## 실행

1. JDK 17 이상을 설치하고 `java --version`, `javac --version`으로 확인합니다.
2. 폴더의 `run.bat`을 실행합니다.

## 주요 기능

- 월간 달력에 날짜별 수입·지출·항목별 비율 막대를 표시합니다. 지출이 큰 날일수록 막대가 길고, 항목 색 구간은 해당 일 지출 내 비중을 나타냅니다.
- 첫 화면에서 초당 수입, 오늘 누적 예정 수입, 근무 진행률을 확인합니다. 진행률 막대는 설정한 근무시간에 따라 자동으로 차오릅니다.
- `급여 · 근무 일정`에서 시급 또는 연봉, 요일별 근무 여부와 시작·종료 시간, 점심시간을 설정합니다. 점심시간은 유급 근무시간에서 자동으로 제외됩니다. 일정이 있는 과거 날짜는 하루 예정 급여를 자동 계산하고, 오늘은 근무 시간 중 경과한 부분만 누적합니다. 미래 일정은 예정 금액으로 표시합니다.
- 날짜를 누르면 오른쪽 패널에서 하루 급여를 직접 저장하거나 지출을 추가·삭제할 수 있습니다. 직접 저장한 수입은 자동 예정 급여보다 우선하며, 결근일은 0원을 저장하면 됩니다. `예정 급여 사용`을 누르면 직접 입력을 지우고 자동 계산으로 돌아갑니다.
- 같은 패널에서 용돈·보너스·기타 수입을 날짜별로 추가할 수 있습니다. 추가 수입은 해당 날짜의 급여와 합산되어 달력과 이번 달 수입에 반영됩니다.
- `비교 보기`를 켜면 작은 창에서 대한민국 대통령·국회의원(2026년 기준), 이재용(삼성전자 급여 기준), 사용자 정의 연봉과 비교합니다.
- 밝은 카드형 UI로 구성했고, 외부 서버·네트워크 없이 로컬에서 실행합니다.

## 로컬 저장

프로그램 폴더의 `data` 디렉터리에 저장됩니다. `run.bat`이 프로그램 폴더를 작업 위치로 지정합니다.

- `expenses.csv`: 날짜·시간, 항목, 금액, 메모
- `daily-income.csv`: 날짜별 직접 입력 수입(자동 예정 수입은 일정·급여 설정에서 계산)
- `allowances.csv`: 날짜별 용돈·보너스·기타 수입
- `settings.properties`: 급여, 주간 근무 일정, 비교 설정

백업은 `data` 폴더를 복사하면 됩니다. CSV와 컴파일 결과는 Git에 포함되지 않도록 설정되어 있습니다.

## 계산 기준

- 시급의 초당 수입은 시급 ÷ 3,600입니다.
- 연봉은 설정한 주간 근무 총시간을 기준으로 연간 52주로 환산합니다. 근무 요일이 없으면 연봉 환산은 주 40시간을 기준으로 합니다.
- 자동 예정 급여는 시작/종료 시간의 경과 비율을 적용합니다. 이 값은 예상치이며 실제 지급액·세전/세후 금액과 다를 수 있습니다.
- 점심시간이 설정된 경우 근무시간과 진행률에서 점심 구간을 제외합니다. 점심시간 중에는 누적 금액이 잠시 멈추고, 종료 후 다시 올라갑니다.
- 비교 수입은 선택한 연봉을 사용자 일정의 주간 근무시간에 맞춰 초당으로 환산한 참고값입니다. 이재용 항목은 삼성전자 공식 급여만 가리키며 배당 등 자산소득은 포함하지 않습니다.

## 자바 수업에서 설명할 클래스

- `TimeIsMoneyApp`: Swing 화면, 일정·달력 이벤트, 실시간 갱신
- `UserSalary`: 급여 방식과 초당 수입 계산
- `Expense`, `DailyIncome`: 지출과 날짜별 직접 입력 수입 데이터
- `AccountBook`: 날짜별 기록과 합계 관리
- `CsvStorage`: CSV 저장·불러오기
- `CalendarDayCell`, `StackedExpenseBar`, `ExpenseTableModel`: 달력 셀, 비율형 막대, 지출 표
